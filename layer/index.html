О проектеAbout the project

Layer продаёт звуки для создания музыки: паки сэмплов и лупов от авторов. Покупатель открывает Mini App прямо в Telegram или сайт, слушает превью и покупает сэмплы за кредиты. Кредиты приходят с подпиской и копятся. Авторы загружают паки через свой кабинет, и каждый сэмпл проходит модерацию, прежде чем появится в магазине.

В таком магазине главное — деньги и контент. Платёж не должен потеряться или пройти дважды, платный файл не должен утечь через прослушивание, а выпуск новой версии не должен ничего сломать.

Layer sells sounds for making music: sample and loop packs from authors. Buyers open the Mini App right inside Telegram or the website, listen to previews and buy samples for credits. Credits come with a subscription and roll over. Authors upload packs through their own portal, and every sample is reviewed before it appears in the store.

In a store like this, money and content come first. A payment must never get lost or go through twice, a paid file must not leak through the preview player, and a new release must not break anything.

Ключевые решенияKey decisions

БезопасностьSecurity

Прослушивание не заменяет покупкуListening is not buying

Если плеер отдаёт ссылку на тот же файл, что и платное скачивание, перебором ссылок можно бесплатно выкачать весь каталог.

Поэтому загрузчик при приёме трека делает через ffmpeg отдельное сжатое превью, и плеер получает только его. Без превью трек не загружается вовсе.

If the player streams the same file as the paid download, anyone can iterate over links and grab the whole catalog for free.

So the uploader renders a separate compressed preview with ffmpeg when a track comes in, and the player only ever gets that. A track without a preview is rejected.

ПлатежиPayments

Деньги списаны — подписка естьCharged means subscribed

Подписку нельзя активировать только по возврату браузера после оплаты: пользователь может закрыть вкладку, и деньги уйдут без подписки.

Её активируют webhook YooKassa и фоновая сверка зависших платежей. Автопродление готово и включается флагом: при повторе после сбоя используется тот же ключ идемпотентности, и карту не списывают дважды за один период.

A subscription can’t rely on the browser coming back after payment: the user may close the tab and lose the money with no subscription.

It is activated by the YooKassa webhook and a background reconciliation of stuck payments. Auto-renewal is built and sits behind a flag: a retry after a crash reuses the same idempotency key, so a card is never charged twice for one period.

КонкурентностьConcurrency

Одна награда — один разOne reward, once

Бот дарит бесплатные скачивания за подписку на каналы. Двойное нажатие «Подписался ✅» или повторная доставка апдейта от Telegram не должны начислять бонус дважды.

Проверка и начисление — одна атомарная операция в базе. Гонку покрывают тесты.

The bot grants free downloads for joining partner channels. A double tap on “Subscribed ✅” or a redelivered Telegram update must not credit the reward twice.

The check and the credit are a single atomic database operation, with tests covering the race.

РелизыReleases

В прод — только проверенный кодOnly verified code ships

Деплой запускается для конкретной версии из ветки main. Сначала все пять приложений проходят проверки, включая интеграционные тесты и Playwright. Образы собираются в CI и закрепляются по digest, секреты не попадают в артефакты GitHub.

Предыдущие релизы сохраняются, откат — тот же запуск с прежней версией.

Deploys run for a specific version from the main branch. All five apps must pass their checks first, including integration tests and Playwright. Images are built in CI and pinned by digest, and secrets never end up in GitHub artifacts.

Previous releases are kept; a rollback is the same run with an earlier version.

Что я сделалWhat I built

  • Сайт и Mini App для покупателей: каталог паков и сэмплов, поиск и фильтры с сортировкой по тональности и BPM, избранное, библиотека покупок, плеер с перемоткой и плавными переходами между превью на Web Audio. Вход на сайт через Telegram.
  • Кабинет авторов и модерация: авторы загружают паки, каждый сэмпл проверяется до публикации. Массовая загрузка аудио, жанры, инструменты и типы, роли сотрудников.
  • Платежи: подписки с оплатой через YooKassa, кредиты копятся между периодами и не теряются при смене тарифа, журнал кредитов, алерты о проблемах с платежами в Telegram.
  • Бот: меню, реферальные ссылки, бонусы за подписку на каналы.
  • Загрузчик: безопасная обработка файлов, превью, миниатюры обложек, анализ треков.
  • Инфраструктура: хранение файлов в S3, сервер, HTTPS через Caddy, автоматический деплой (CI/CD), стенд для тестировщиков, ночные бэкапы.
  • Website and Mini App for buyers: a catalog of packs and samples, search and filters with key and BPM sorting, favorites, a purchase library, a player with seeking and smooth transitions between previews on Web Audio. Website sign-in with Telegram.
  • Author portal and moderation: authors upload packs, and every sample is reviewed before it goes live. Bulk audio upload, genres, instruments and types, staff roles.
  • Payments: subscriptions paid through YooKassa, credits that roll over and survive plan changes, a credit ledger, Telegram alerts on payment problems.
  • Bot: menu, referral links, rewards for joining channels.
  • Uploader: safe file handling, previews, cover thumbnails, track analysis.
  • Infrastructure: S3 file storage, the server, HTTPS via Caddy, automated deployment (CI/CD), a staging stand for testers, nightly backups.
